# Resource 存档系统

## 核心概念

基于 `Resource` 类实现存档，适合保存多样复杂的场景数据。默认 Resource 不能保存数据，需要**自定义继承 Resource 的子类**作为数据载体。

## 关键节点/类及作用

| 节点/类               | 作用              | 关键用法                                             |
| ------------------ | --------------- | ------------------------------------------------ |
| **自定义 Resource 类** | 存档的数据结构载体       | `extends Resource` + `class_name SceneData`      |
| `@export var`      | 声明可序列化保存的变量     | `@export var player_position: Vector2`           |
| `ResourceSaver`    | 将 Resource 写入硬盘 | `ResourceSaver.save(data, "user://...")`         |
| `ResourceLoader`   | 从硬盘读取存档         | `ResourceLoader.load("user://...") as SceneData` |
| `PackedScene`      | 将整个节点打包保存       | `.pack(node)` 打包 → `.instantiate()` 还原           |
| **Group（分组）**      | 给节点打标签，批量获取     | `get_tree().get_nodes_in_group("box")`           |

## 使用方法

### 1. 创建自定义存档数据类

```gdscript
extends Resource
class_name SceneData

@export var player_position: Vector2
@export var is_facing_left: bool
@export var box_array: Array[PackedScene]
```

### 2. 保存存档

```gdscript
func save():
    var data = SceneData.new()
    data.player_position = player.global_position
    data.is_facing_left = player.get_child(0).flip_h

    # 保存场景中的节点（打包成 PackedScene）
    var boxes = get_tree().get_nodes_in_group("box")
    for box in boxes:
        var box_packed = PackedScene.new()
        box_packed.pack(box)
        data.box_array.append(box_packed)

    ResourceSaver.save(data, "user://save_data.tres")
    print("保存成功")
```

### 3. 读取存档

```gdscript
func load_game():
    var data = ResourceLoader.load("user://save_data.tres") as SceneData
    if not data:
        return

    # 恢复玩家
    player.global_position = data.player_position
    player.get_child(0).flip_h = data.is_facing_left

    # 删除旧箱子，生成新箱子
    for box in get_tree().get_nodes_in_group("box"):
        box.queue_free()

    for box_packed in data.box_array:
        var box_node = box_packed.instantiate()
        get_tree().current_scene.add_child(box_node)
```

## 注意事项

### 文件路径与格式

- **`user://` 路径**：不在游戏文件夹内，更新/删除游戏不影响存档。不同系统路径不同。
- **`.res` 后缀**：二进制格式，乱码但性能好、更安全。
- **`.tres` 后缀**：文本格式，人类可读，便于开发和调试。

### `@export` 关键字

必须加 `@export`，变量才能被序列化保存到文件中。

### 大量物理物体加载 Bug

- **问题**：大量 `RigidBody2D` 同时生成时，物理引擎计算跟不上，物体会**乱飞**。
- **解决方案**（[!] 重点）：
  1. 生成时设置 `box_node.freeze = true`（暂停物理计算）
  2. 所有箱子生成完毕后，等待短暂时间（0.1s）：
     ```gdscript
     await get_tree().create_timer(0.1).timeout
     ```
  3. 再遍历解冻所有箱子：
     ```gdscript
     for box in get_tree().get_nodes_in_group("box"):
         box.freeze = false
     ```

### 与其他存档方式对比

| 方式 | 特点 |
|-----|------|
| **Resource** | 较均衡，适合复杂场景数据 |
| ConfigFile | 适合简单配置、小体量游戏 |
| JSON / 二进制序列化 | 各有侧重（大小/安全/灵活） |

## 场景节点连接

- 在 UI 节点挂载存档脚本
- 用 `@export var player: Node2D` 拖拽绑定玩家节点
- 保存/读取按钮的 `pressed` 信号连接到脚本的 `save()` / `load_game()` 函数

# ConfigFile 存档系统

## 核心概念

使用 Godot 内置的 `ConfigFile` 类将数据保存为本地文件。适合保存玩家设置、成就等少量数据，尤其适合**小体量游戏**开发。支持**加密**功能防止玩家篡改存档。

## 关键节点/类及作用

| 节点/类 | 作用 | 关键用法 |
|---------|------|---------|
| **ConfigFile** | 创建/读取配置文件对象 | `ConfigFile.new()` |
| `LineEdit` | 玩家文本输入（如名字） | `.text` 属性获取字符串 |
| `ColorPickerButton` | 玩家颜色选择器 | `.color` 属性获取颜色 |
| `@export var` | 绑定 UI 节点到脚本 | `@export var player_name: LineEdit` |
| `pressed` 信号 | 按钮点击触发保存/加载 | 连接到 `save()` / `load()` 函数 |
| `user://` | 跨平台安全存档路径 | Windows → `%appdata%/Godot/app_user_data/<项目名>/` |

## 使用方法

### 1. 创建脚本并绑定 UI 节点

在场景根节点（如 CanvasLayer）挂载脚本，用 `@export` 声明需要读取的 UI 节点：

```gdscript
extends CanvasLayer

@export var player_name: LineEdit         # 绑定输入框节点
@export var player_color: ColorPickerButton  # 绑定颜色选择器节点
```

在编辑器的**检查器**中，将对应的场景节点拖拽绑定到变量上。

### 2. 连接按钮信号

选中保存/加载按钮 → 检查器 → **Node** 板块 → **Signals** 面板 → 双击 `pressed` 信号：

- **连接目标**：挂载脚本的节点（CanvasLayer）
- **函数名称**：`save` / `load`

Godot 会自动生成函数：

```gdscript
func save():
    pass

func load():
    pass
```

### 3. 保存数据

```gdscript
func save():
    # 1. 创建 ConfigFile 对象
    var config = ConfigFile.new()

    # 2. 写入数据（分区, 键名, 数据）
    config.set_value("settings", "name", player_name.text)
    config.set_value("settings", "color", player_color.color)

    # 3. 保存到硬盘（user:// 路径）
    config.save("user://settings.cfg")

    print("保存成功")
```

> **`set_value(section, key, value)` 参数说明**：
> - **section**：数据分区，多人游戏可用来区分不同玩家
> - **key**：数据索引名，用于在分区内查找数据
> - **value**：要保存的数据本身

### 4. 读取数据

```gdscript
func load():
    var config = ConfigFile.new()

    # 加载文件，返回状态结果
    var result = config.load("user://settings.cfg")

    if result == OK:
        # 成功：从分区中读取数据
        player_name.text = config.get_value("settings", "name")
        player_color.color = config.get_value("settings", "color")
    else:
        # 失败：文件不存在或损坏
        printerr("加载存档失败")
```

> `config.load()` 返回 `OK`（成功）或错误码，可用 `if result == OK` 判断。

## 文件保存位置

| 系统 | 路径 |
|------|------|
| **Windows** | `%appdata%/Godot/app_user_data/<项目名>/` |
| **macOS** | `~/Library/Application Support/Godot/app_user_data/<项目名>/` |
| **Linux** | `~/.local/share/godot/app_user_data/<项目名>/` |

> Windows 下按 `Win + R` → 输入 `%appdata%` → 打开 `Godot/app_user_data/<项目名>` 即可找到存档文件。

## 加密存档

为了防止玩家直接修改存档文件，可以使用 `ConfigFile` 的加密功能：

```gdscript
# 密钥（实际开发中不要直接写在代码里，防止被解包读取）
var key: String = "my_secret_key"

func save_encrypted():
    var config = ConfigFile.new()
    config.set_value("settings", "name", player_name.text)
    config.set_value("settings", "color", player_color.color)

    # 使用 save_encrypted_pass() 替代 save()
    config.save_encrypted_pass("user://settings.cfg", key)
    print("加密保存成功")

func load_encrypted():
    var config = ConfigFile.new()

    # 使用 load_encrypted_pass() 替代 load()
    var result = config.load_encrypted_pass("user://settings.cfg", key)

    if result == OK:
        player_name.text = config.get_value("settings", "name")
        player_color.color = config.get_value("settings", "color")
    else:
        printerr("加载加密存档失败")
```

> **加密效果**：用文本编辑器打开存档文件会看到**乱码**，玩家无法直接修改。必须使用相同的密钥才能解密读取。

> **安全提示**：密钥不要硬编码在脚本中。如果有玩家解包游戏，可以直接读取到密钥。建议将密钥存储在更安全的位置或进行混淆处理。

## 完整脚本示例

```gdscript
extends CanvasLayer

@export var player_name: LineEdit
@export var player_color: ColorPickerButton

var key: String = "my_secret_key"  # 建议不要硬编码

func save():
    var config = ConfigFile.new()
    config.set_value("settings", "name", player_name.text)
    config.set_value("settings", "color", player_color.color)
    config.save_encrypted_pass("user://settings.cfg", key)
    print("保存成功")

func load():
    var config = ConfigFile.new()
    var result = config.load_encrypted_pass("user://settings.cfg", key)

    if result == OK:
        player_name.text = config.get_value("settings", "name")
        player_color.color = config.get_value("settings", "color")
    else:
        printerr("加载存档失败")
```

## 支持的数据类型

ConfigFile 可以保存 Godot 中的绝大部分数据类型：

| 类型 | 示例 |
|------|------|
| `String` | 字符串 |
| `int` | 整数 |
| `float` | 浮点数 |
| `Color` | 颜色 |
| `Vector2` / `Vector3` | 向量 |
| `Array` | 数组 |
| `Dictionary` | 字典 |
| 自定义类型 | 自定义 Resource 等 |

## 优缺点对比

| 方面 | ConfigFile | Resource |
|------|-----------|----------|
| **实现复杂度** | 低，开箱即用 | 中等，需自定义类 |
| **加密支持** | 内置加密 | 无内置加密 |
| **适合场景** | 简单配置、玩家设置、小体量游戏 | 复杂场景数据、大量节点状态 |
| **数据量** | 不适合大量数据 | 可承载较多数据 |
| **编辑器集成** | 无 | 可在编辑器直接创建/编辑 |
