# Godot 2D 节点完整指南

## Node2D — 一切开始的地方

`Node2D` 是所有 2D 节点的**基类**，管理：
- **位置** (position)
- **旋转** (rotation)
- **缩放** (scale)

本文介绍的所有节点都直接或间接继承自 `Node2D`。

---

## 🔲 碰撞系统

这些节点构成了 Godot 2D 物理碰撞的基础。

| 节点 | 说明 |
|------|------|
| [[CollisionObject2D]] | 所有碰撞物体的基类（不可单独使用）。包含碰撞层、启用开关等属性。 |
| [[PhysicsBody2D]] | 所有受物理影响的 2D 物体的基类（不可单独使用）。 |
| [[CollisionShape2D]] | 为物理体设置碰撞形状，必须是物理体的子节点。 |
| [[CollisionPolygon2D]] | 用多边形定义碰撞形状，同上。 |
| [[Raycast2D]] | 发射无限细的线检测直线碰撞，报告是否命中、碰撞点和碰撞对象。 |
| [[Shapecast2D]] | 类似 Raycast2D，但用形状（矩形/圆形等）检测碰撞。 |

---

## ⚙️ 物理体 (Physics Bodies)

| 节点 | 说明 |
|------|------|
| [[RigidBody2D]] | 受重力和其它物理体影响的刚体。用于可移动的非玩家物理物品。 |
| [[CharacterBody2D]] | 专为玩家控制设计的物理体，内置精确控制移动的 API。 |
| [[StaticBody2D]] | 不可移动的物理体。其他物理体可受它影响。适用于墙壁、地板、天花板。移动它会直接瞬移，不会推动其他物体。 |
| [[AnimatableBody2D]] | 几乎和 StaticBody2D 一样，但**可以移动**。不受重力影响，但移动时会推动挡路的物理体。 |

---

## 🔗 物理关节 (Joints)

> `Joint2D` 是所有 2D 物理关节的基类（不可单独使用）。用于连接两个物理体。

| 节点 | 说明 |
|------|------|
| [[DampenedSpringJoint2D]] | 像弹簧一样连接两个物理体，包含弹簧长度、刚度和阻尼参数。 |
| [[GrooveJoint2D]] | 像活塞一样连接两个物理体，只能沿一个运动轴伸缩。 |
| [[PinJoint2D]] | 将两个物理体钉在一起，在一个点连接并可自由旋转。 |

---

## 🌊 Area2D

`Area2D` 有两种用途：
1. **检测**碰撞对象进入或离开区域。
2. 创建拥有**独立物理和音频设置**的空间区域（如改变重力、风、音频通道，实现水下区域或零重力区域）。

---

## 🎨 视觉与精灵 (Visual / Sprites)

| 节点 | 说明 |
|------|------|
| [[Sprite2D]] | 在屏幕上渲染 2D 纹理，可显示大图集的一部分。 |
| [[AnimatedSprite2D]] | Sprite2D 的扩展，内置精灵表动画工具。 |
| [[TileMap]] | 用于构建 2D 瓦片地图，内置瓦片集工具，可为瓦片分配物理层和导航层。 |
| [[Polygon2D]] | 在 2D 中设置多边形形状，可通过代码添加点或在编辑器中拖放。 |
| [[Line2D]] | 向点数组添加点来绘制 2D 线条。支持宽度、渐变、圆角等样式属性。 |
| [[MeshInstance2D]] | 在 2D 中渲染 3D 网格（模型）。 |
| [[MultiMeshInstance2D]] | 高效渲染大量网格（如一片草地）。建议大量网格密集时使用。 |

---

## 📷 相机与视差

| 节点 | 说明 |
|------|------|
| [[Camera2D]] | 定义场景的 2D 观察视角，包含旋转、位置参数，支持拖拽和平滑效果。 |
| [[ParallaxBackground]] | 与 ParallaxLayer 配合，设置 2D 视差滚动背景。 |
| [[ParallaxLayer]] | 视差图层，任何 2D 图形作为其子节点即可产生视差效果。 |

---

## 💡 2D 光照系统

| 节点 | 说明 |
|------|------|
| [[CanvasModulate]] | 设置 2D 阴影前先让场景变暗，以便 2D 光源重新照亮。 |
| [[Light2D]] | 所有 2D 光源的基类（不可单独使用），包含光色、能量和混合模式设置。 |
| [[PointLight2D]] | 点光源，从一个点照亮场景。需要指定纹理决定光照外观，阴影从中心点投射。 |
| [[DirectionalLight2D]] | 方向光，一次性照亮整个场景，模拟太阳或月亮。阴影不会随距离扭曲。 |
| [[LightOccluder2D]] | 用于在场景中投射阴影的形状。设置形状后即可投射阴影。 |

---

## 🔉 音频

| 节点 | 说明 |
|------|------|
| [[AudioListener2D]] | 默认相机是 2D 音频监听点。如需从其他位置收听，用此节点设置监听点。 |
| [[AudioStreamPlayer2D]] | 2D 音频源，从空间某点播放音频。支持音量、音调、范围、衰减等设置。 |

---

## ✨ 粒子系统 (Particles)

| 节点 | 说明 |
|------|------|
| [[CPUParticles2D]] | CPU 驱动的 2D 粒子系统。 |
| [[GPUParticles2D]] | GPU 驱动的 2D 粒子系统。 |

> 参数非常多但很直观，推荐添加到场景中调整参数来学习。

## 🧭 导航 (Navigation)

| 节点 | 说明 |
|------|------|
| [[NavigationRegion2D]] | 设置 2D 导航区域，需要手动设置导航区域（比 3D 复杂，3D 有自动生成工具）。 |
| [[NavigationLink2D]] | 导航链接，连接不同导航区域。 |
| [[NavigationObstacle2D]] | 导航障碍物，用于动态避障。 |

---

## 🦴 骨骼与动画 (Skeleton)

| 节点 | 说明 |
|------|------|
| [[Skeleton2D]] | 搭建 2D 骨骼系统的根节点。 |
| [[Bone2D]] | 骨骼中的单个骨头节点。 |
| [[PhysicalBone2D]] | 受物理影响的骨骼节点。 |

---

## 🛠️ 路径 / 工具节点

| 节点 | 说明 |
|------|------|
| [[Path2D]] | 设置 2D 路径或曲线。 |
| [[PathFollow2D]] | 作为 Path2D 的子节点，将另一个节点绑定到路径上运动。 |
| [[Marker2D]] | 调试节点，在编辑器中显示位置和旋转，用于标记不可见节点或空间中的点。 |
| [[RemoteTransform2D]] | 将自身变换同步给另一节点（虚拟父级），可选择影响位置、旋转、缩放或全部。 |

---

## 📺 可见性检测

| 节点 | 说明 |
|------|------|
| [[VisibleOnScreenNotifier2D]] | 检测视觉元素是否在屏幕上，可见时发送信号。 |
| [[VisibleOnScreenEnabler2D]] | 检测视觉元素是否在屏幕上，可见时自动启用自身。 |

---

## 🎞️ 渲染特效 (Rendering)

| 节点 | 说明 |
|------|------|
| [[CanvasGroup]] | 将所有子节点合并为一次绘制调用。适合合并半透明瓶子和内容等纹理。 |
| [[BackBufferCopy]] | 捕获屏幕区域供着色器使用，在着色器中通过 `hint_screen_texture` 变量访问。 |
