# 战争迷雾 Fog of War

## 概述

战争迷雾（Fog of War）是策略/探索类游戏中的常用技术，通过遮挡未探索区域的地图和实体，为玩家带来不确定性和挑战。

本教程使用 Godot 引擎的 `Image` / `ImageTexture` 和着色器（Shader）实现 2D 战争迷雾，包含：
- 玩家移动探索点亮地图
- 可再生迷雾机制（玩家离开后区域被半透明迷雾重新覆盖）
- NPC 仅在玩家视野范围内显示

---

## 原理

1. 游戏开始时生成一张**全白图片**作为迷雾
2. 玩家移动时，像**黑色画笔**一样将经过区域涂黑
3. 着色器根据图片**黑/白**决定迷雾是否在该位置显示：
   - **白色** → 迷雾不透明（看不见）
   - **黑色** → 迷雾透明（已探索）

---

## 实现步骤

### 1. 场景搭建

在场景树中新建一个 **Sprite2D** 节点作为迷雾层，确保它在最上层以覆盖其他内容。

### 2. 迷雾脚本

为 Sprite2D 节点添加脚本，核心变量：

```gdscript
@export var fog_width: int = 500        # 迷雾宽度（像素）
@export var fog_height: int = 300       # 迷雾高度（像素）
@export var light_texture: Texture2D    # 画笔纹理
@export var player: CharacterBody2D     # 玩家节点

var fog_image: Image                     # 迷雾图片
var fog_texture: ImageTexture            # 迷雾纹理
var light_image: Image                   # 画笔图片（从 light_texture 转换）
```

#### 初始化迷雾

在 `_ready()` 中生成全白迷雾：

```gdscript
func _ready():
    # 创建迷雾图片
    fog_image = Image.create(fog_width, fog_height, false, Image.FORMAT_RGBA8)
    fog_image.fill(Color.WHITE)
    
    # 创建迷雾纹理并赋值给 Sprite2D
    fog_texture = ImageTexture.create_from_image(fog_image)
    self.texture = fog_texture
    
    # 将画笔纹理转为图片
    light_image = light_texture.get_image()
    
    # 初始化当前帧纹理
    current_image = fog_image.duplicate()
    current_texture = fog_texture.duplicate()
    
    # 设置着色器中的第二个纹理
    material.set_shader_parameter("current_texture", current_texture)
    
    # 初始点亮玩家位置
    update_fog()
```

### 3. 画笔纹理（Light Texture）

在检查器中为 `light_texture` 创建一个 **GradientTexture2D**：

- **Fill** → `radial`（径向渐变）
- **Fill From** → `(0.5, 0.5)`
- **Fill To** → `(0.5, 0.0)`
- **Gradient 颜色** → 黑色到透明渐变
- **尺寸** → `64 × 64`（控制视野范围）

> 💡 这个圆形渐变纹理就是玩家的"视野笔刷"。

### 4. 更新迷雾（核心函数）

```gdscript
func update_fog():
    if player.velocity != Vector2.ZERO:
        # 将玩家世界坐标转换为迷雾图片上的像素坐标
        var player_pos = player.global_position + Vector2(fog_width, fog_height) / 2
        # 减去画笔中心偏移
        player_pos -= Vector2(light_image.get_size()) / 2
        
        # 将画笔涂到迷雾图片上
        fog_image.blend_rect(
            light_image,
            Rect2i(Vector2i.ZERO, light_image.get_size()),
            player_pos
        )
        # 更新纹理
        fog_texture.update(fog_image)
```

在 `_process()` 中调用：

```gdscript
func _process(delta):
    if player.velocity != Vector2.ZERO:
        update_fog()
```

---

### 5. 着色器（Shader）

创建 **ShaderMaterial** 并编写着色器：

```glsl
shader_type canvas_item;

uniform vec4 fog_color : source_color = vec4(0.5, 0.5, 0.5, 1.0);  // 迷雾颜色
uniform sampler2D current_texture;                                    // 当前帧纹理

void fragment() {
    // 采样两张纹理
    float fog_alpha = texture(TEXTURE, UV).r;
    float current_alpha = texture(current_texture, UV).r;
    
    // 取平均值 = 离开区域半透明，当前区域完全透明
    float final_alpha = (fog_alpha + current_alpha) / 2.0;
    
    COLOR.rgb = fog_color.rgb;
    COLOR.a = final_alpha;
}
```

> **说明**：`TEXTURE` 是 Godot 自动传入 Sprite2D 的纹理（即第一张迷雾纹理）。通过组合两张纹理，实现"离开后半透明覆盖"的效果。

## 6. 可再生迷雾机制

使用**两张纹理**实现：

| 纹理 | 用途 | 更新方式 |
|------|------|---------|
| `fog_image` / `fog_texture` | 记录玩家所有**走过**的路径 | 每帧累加绘制 |
| `current_image` / `current_texture` | 记录玩家**当前位置**（仅当前帧） | 每帧先清空（fill white），再绘制当前位置 |

```gdscript
func update_fog():
    # 每帧先擦除当前帧图片（重置为全白）
    current_image.fill(Color.WHITE)
    
    # 绘制玩家当前位置到 current_image
    var player_pos = player.global_position + Vector2(fog_width, fog_height) / 2
    player_pos -= Vector2(light_image.get_size()) / 2
    
    current_image.blend_rect(
        light_image,
        Rect2i(Vector2i.ZERO, light_image.get_size()),
        player_pos
    )
    current_texture.update(current_image)
    
    # 同时更新累积的迷雾纹理
    fog_image.blend_rect(
        light_image,
        Rect2i(Vector2i.ZERO, light_image.get_size()),
        player_pos
    )
    fog_texture.update(fog_image)
```

着色器中取 `(fog_alpha + current_alpha) / 2.0`：
- **玩家当前位置** → `current_alpha = 0` → `final_alpha ≈ 0` → 完全透明（可见）
- **已探索但已离开** → `fog_alpha = 0, current_alpha = 1` → `final_alpha = 0.5` → 半透明
- **未探索** → `fog_alpha = 1, current_alpha = 1` → `final_alpha = 1` → 不透明（隐藏）

## 7. NPC 视野隐藏

为 NPC 添加脚本，根据与玩家的距离控制可见性：

```gdscript
@export var player: CharacterBody2D

func _process(delta):
    # 使用距离平方避免开根号运算
    var dist_sq = global_position.distance_squared_to(player.global_position)
    var view_radius = 32  # 视野半径（画笔尺寸的一半）
    
    visible = dist_sq <= view_radius * view_radius
```

## 完整代码结构

### 迷雾层脚本（Sprite2D）

```gdscript
extends Sprite2D

@export var fog_width: int = 500
@export var fog_height: int = 300
@export var light_texture: Texture2D
@export var player: CharacterBody2D

var fog_image: Image
var fog_texture: ImageTexture
var light_image: Image
var current_image: Image
var current_texture: ImageTexture

func _ready():
    # 初始化迷雾
    fog_image = Image.create(fog_width, fog_height, false, Image.FORMAT_RGBA8)
    fog_image.fill(Color.WHITE)
    fog_texture = ImageTexture.create_from_image(fog_image)
    self.texture = fog_texture
    
    # 画笔
    light_image = light_texture.get_image()
    
    # 当前帧纹理（可再生迷雾用）
    current_image = fog_image.duplicate()
    current_texture = fog_texture.duplicate()
    material.set_shader_parameter("current_texture", current_texture)
    
    update_fog()

func _process(delta):
    if player.velocity != Vector2.ZERO:
        update_fog()

func update_fog():
    # 擦除当前帧
    current_image.fill(Color.WHITE)
    
    var player_pos = player.global_position + Vector2(fog_width, fog_height) / 2
    player_pos -= Vector2(light_image.get_size()) / 2
    
    # 绘制玩家当前位置
    current_image.blend_rect(
        light_image,
        Rect2i(Vector2i.ZERO, light_image.get_size()),
        player_pos
    )
    current_texture.update(current_image)
    
    # 更新累积迷雾
    fog_image.blend_rect(
        light_image,
        Rect2i(Vector2i.ZERO, light_image.get_size()),
        player_pos
    )
    fog_texture.update(fog_image)
```

## 扩展思路

- **多梯队战斗迷雾**：基于这套双层纹理机制，扩展到多层迷雾（如：未探索 → 已探索 → 视野内 → 单位视野）
- **涂鸦效果**：相同的 `blend_rect` + 纹理技术可用于做地图绘制/涂鸦
- **不同地形视野**：根据地形类型动态修改画笔大小或形状
- **敌军视野**：添加敌方单位的视野纹理，实现"敌方视野"的迷雾揭示
