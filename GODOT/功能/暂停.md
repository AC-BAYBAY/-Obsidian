# 暂停系统

## 节点结构

```
CanvasLayer (PauseMenu)
├── Process Mode: Always    ← 暂停时UI仍能响应
├── TextureButton           ← 暂停按钮 (右上角)
├── Panel (PausePanel)      ← 暂停面板，默认隐藏，铺满全屏
│   ├── ResumeButton        ← 文字 "RESUME"，点击继续游戏
│   └── QuitButton          ← 文字 "QUIT"，点击退出游戏
└── AudioStreamPlayer (PauseSound)  ← 按钮点击音效
```

> [!important] 关键设置
> - `CanvasLayer` 的 **Process Mode** 必须设为 `Always`，否则暂停后 UI 无法响应输入。
> - 所有按钮的 **Focus Mode** 设为 `None`，防止空格键意外触发。

---

## 脚本逻辑

挂载到 `CanvasLayer`，核心变量与函数：

```gdscript
@export var pause_panel : Panel
@export var bgm_player : AudioStreamPlayer
@export var pause_sound : AudioStreamPlayer
var pause_time : float = 0.0
```

### 暂停

```gdscript
func pause():
    get_tree().paused = true
    pause_panel.visible = true
    pause_sound.play()
    pause_time = Time.get_ticks_msec() / 1000.0
```

### 继续

```gdscript
func unpause():
    get_tree().paused = false
    pause_panel.visible = false
    pause_sound.play()
```

### 退出游戏

```gdscript
func quit_game():
    get_tree().quit()
```

## ESC 键切换暂停

```gdscript
func _input(event):
    if event is InputEventKey:
        if event.keycode == KEY_ESCAPE and event.pressed:
            if not get_tree().paused:
                pause()
            else:
                unpause()
```

## BGM 淡入淡出

在 `_process(delta)` 中实现平滑音量过渡，并在淡出完成后暂停音频流：

```gdscript
func _process(delta):
    var linear_volume = db_to_linear(bgm_player.volume_db)
    var target_volume = 0.0 if get_tree().paused else 1.0
    linear_volume = lerp(linear_volume, target_volume, delta * 15.0)
    bgm_player.volume_db = linear_to_db(linear_volume)

    if get_tree().paused and (Time.get_ticks_msec() / 1000.0 - pause_time) > 0.3:
        bgm_player.stream_paused = true
    else:
        bgm_player.stream_paused = false
```

> [!info] 原理
> `CanvasLayer` 的 **Process Mode** 设为 `Always`，暂停后 `_process` 仍能运行。利用这一特性完成 **0.3 秒的淡出过渡**，之后才真正暂停 BGM 音频流。恢复时同理，立即取消暂停流，音量逐渐淡入。

## 按钮音效

- 在 `CanvasLayer` 下添加 `AudioStreamPlayer`，节点名 `PauseSound`，加载点击音效资源。
- 在 `pause()` 和 `unpause()` 中调用 `pause_sound.play()`。

---

## 完整脚本示例

```gdscript
extends CanvasLayer

@export var pause_panel : Panel
@export var bgm_player : AudioStreamPlayer
@export var pause_sound : AudioStreamPlayer
var pause_time : float = 0.0


func _input(event):
    if event is InputEventKey:
        if event.keycode == KEY_ESCAPE and event.pressed:
            if not get_tree().paused:
                pause()
            else:
                unpause()


func _process(delta):
    var linear_volume = db_to_linear(bgm_player.volume_db)
    var target_volume = 0.0 if get_tree().paused else 1.0
    linear_volume = lerp(linear_volume, target_volume, delta * 15.0)
    bgm_player.volume_db = linear_to_db(linear_volume)

    if get_tree().paused and (Time.get_ticks_msec() / 1000.0 - pause_time) > 0.3:
        bgm_player.stream_paused = true
    else:
        bgm_player.stream_paused = false


func pause():
    get_tree().paused = true
    pause_panel.visible = true
    pause_sound.play()
    pause_time = Time.get_ticks_msec() / 1000.0


func unpause():
    get_tree().paused = false
    pause_panel.visible = false
    pause_sound.play()


func quit_game():
    get_tree().quit()
```
